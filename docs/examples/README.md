# Examples

Runnable, maintained examples of the public model and composition workflows.

- [Workplace SIR](sir.md) — deterministic population generation, execution, overrides, and verification.
- [SIR policy feedback](sir_policy.md) — two-box delayed feedback and common-random-number comparison.
- [Canonical finite-state models](canonical-models.md) — two-state, decay, SIS, SEIRS, and noisy-voter examples.
- [Composition showcase](composition-showcase.md) — counterfactuals, policy fan-out, surveillance, and nested regional composition.

The corresponding artifacts live under `examples/` and `fixtures/`. Examples should use current public workflows; frozen evidence belongs under [`../evidence/`](../evidence/README.md).
