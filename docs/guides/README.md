# Guides

Maintained task-oriented documentation for authoring and running Sembla models.

- [ABS data pipeline](abs-data.md) — pinned ABS acquisition, canonical extracts, reconciliation, and documented coverage limits.
- [Composition](composition.md) — author components, export sources, link plans, build bundles, compare runs, and reason about stable identities.
- [State artifacts](state-format.md) — portable population and final-state files, chained runs, hashes, and schema checks.
- [Visual guide](visual-guide.md) — diagrams of boxes, tables, wires, transitions, and representative models.

For Lean syntax and frontend tooling, see the [frontend guide](../../frontend/README.md). For runnable models, see the [examples index](../examples/README.md).
