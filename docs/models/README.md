# Model documentation

Maintained descriptions of substantive model fixtures and driver models.

- [Demographic slot model](demographic.md) — aggregate births, deaths, migration, chained windows, calibration artifacts, and explicit scientific limitations.
- [Australian population](australian-population.md) — eight-state identity-preserving movement, deterministic ABS initial state, and accepted model limits.
- [ABS data pipeline](../guides/abs-data.md) — pinned source vintages, canonical demographic extracts, reconciliation, and documented coverage limits.

Runnable pedagogical models live under the [examples index](../examples/README.md). Model descriptions must distinguish software-validation fixtures from empirically calibrated models.
