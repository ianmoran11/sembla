Method & assumptions

Transparent arithmetic, not a benchmark.

MODEL
—
  • GPU vendors advertise decimal GB; results also show binary GiB.
  • Multi-GPU counts assume perfect, even sharding with no duplicated metadata.
  • Capacity does not imply enough memory bandwidth, compute, or interconnect throughput.
  • Sembla’s exact CUDA scratch space varies with transitions, candidates, aggregates, and outputs.
  • † Max agents assumes one system replica with the same per-agent shape and current overheads.
  • Catalog capacities are representative; verify the exact SKU before purchasing or renting.
