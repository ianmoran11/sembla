# NPE reference artifacts

This directory contains the curated, committed evidence from the CPU-only NPE
reference pipeline. It intentionally excludes reproducible intermediates:
`population.bin`, `heldout-theta.json`, `training-sweep/`, `heldout-sweep/`,
and timestamped `training-log/` directories.

The committed set is:

- `training-pairs.csv` and its exporter-produced metadata sidecar;
- `heldout-pairs.csv` and its exporter-produced metadata sidecar;
- `run/{diagnostics.json,posterior-samples.csv,posterior.pt}`; and
- `repro-run/{diagnostics.json,posterior-samples.csv,posterior.pt}`.
